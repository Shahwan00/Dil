# Learnella — UI prototype

هذا المشروع يعيد بناء واجهات تطبيق التعلم الظاهرة في الصورة كـ Web App مستقل باستخدام HTML + CSS + JavaScript فقط.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح.
3. لا يحتاج المشروع إلى Node.js أو Firebase في النسخة الحالية.

## الشاشات الموجودة
- Splash / Logo
- Login
- Sign up
- Forgot password
- Verification
- Welcome / onboarding
- Select level
- Select subject
- Home dashboard
- Courses
- Course details
- Lesson
- Quiz
- Teachers
- Teacher profile
- Booking
- Payment
- Payment success
- Calendar
- Chat
- Profile
- Settings

## ملاحظات
هذه نسخة Front-end قابلة للتشغيل، وليست نسخة إنتاجية مرتبطة بقاعدة بيانات أو بوابة دفع حقيقية.
يمكن ربط نفس الواجهات لاحقاً بـ Firebase Authentication + Firestore + Storage، وإضافة React إذا أردت تحويلها إلى مشروع احترافي أكبر.
